WHAT IS HAG?

ゲームを作ったことがなくても、その日に遊べるところまで。ゲームを作ったことがなくても、その日に遊べるところまで。

HAGは、AIを相棒にゲームを企画・制作し、発表と試遊まで行う1dayイベントです。プログラミングや絵の経験は問いません。

1名での申込も、友人との申込も歓迎。制作は当日必ずチームで行い、事前チームがない方は会場でチームを編成します。

01はじめて作るAIの使い方と制作の進め方をサポート
02腕を試す限られた時間でゲーム性を研ぎ澄ます
03仲間と出会うAI・企画・ゲームに前のめりな人とつながる
02

BUILD THE CORE

完成度より、ゲーム性の核。

作るのは、ゲームのMVP。

壮大な設定や大量のステージではなく、「この操作が面白い」「もう一回遊びたい」と思える最小限のゲームを目指します。AIは、アイデアを遊べる形へ変えるための制作パートナーです。

  1. 01

    面白さをひとつ決める

    誰が、何をすると面白いのかを言葉にする。

  2. 02

    AIと最短で実装する

    機能を絞り、まず動いて遊べる状態をつくる。

  3. 03

    見せて、遊んでもらう

    狙いを発表してから試遊し、反応を確かめる。

03

DAY SCHEDULE

1日で、企画から発表・試遊まで。

発表で各作品の面白さを知ってから、気になるゲームを実際に遊びます。時刻は運営状況により微調整する場合があります。

  1. 10:00
    開会・チームづくり趣旨説明、チーム編成、アイスブレイク
  2. 11:00
    ルール・審査基準MVP、提出方法、制作環境を確認
  3. 11:30
    企画・ゲーム制作面白さの核を決め、AIと一気に形にする
  4. 15:30
    MVP中間確認遊べる状態を確認し、必要なら機能を削る
  5. 17:00
    Code Freeze・提出ビルド、操作方法、作品説明を提出
  6. 17:15
    協賛企業LT企業・技術・キャリアのショートトーク
  7. 17:40
    10チーム発表面白さの核と、試してほしいポイントを紹介
  8. 18:40
    並行試遊・審査気になる作品を遊び、審査員が全作品を確認
  9. 19:25
    投票・審査集計観客投票、軽食配布、審査集計
  10. 19:45
    表彰・スポンサー賞受賞作品と選出理由を発表
  11. 20:05
    公式懇親会参加者、審査員、協賛企業が交流
  12. 21:05
    自由交流・自由試遊作品へのフィードバック、自由解散
  13. 22:15
    締め・集合写真22:30参加者退出、23:00撤収完了

ORGANIZER

HAG発起人・主催

町原 悠太

北海道大学工学部 情報学科3年（休学中）

大学からゲーム制作を始め、SAOへの強い憧れからVRゲームやVRコンテンツ制作に取り組む。東京で複数のハッカソンに参加し、札幌と東京のテックコミュニティの質と量の差に圧倒された。

札幌にも、挑戦を始める場所と制作を通じて仲間に出会う機会を増やしたいと考え、HAGを企画。1年後に札幌でゲーム会社を立ち上げる予定で、一緒に挑戦する仲間を募集中。
