SECURITY

安全な決済と、必要最小限の情報管理。

カード情報を保持しません

カード決済はStripeが提供するホスト型のPayment Linksで行います。SAKIMISEのサイトやサーバーにはカード番号、セキュリティコード等を入力・保存・送信する仕組みを置きません。

安全な通信

公開サイトと決済ページはいずれもHTTPSを使用します。SAKIMISEからお送りする決済リンクのドメインがStripeの正規ドメインであることをご確認ください。

攻撃対象を最小化します

SAKIMISEのサービスサイトは静的構成で、会員登録、ログイン、ファイルアップロード、データベース、独自のカード入力フォームを設けていません。公開領域に顧客データ、決済データ、認証情報を配置しません。

管理と点検

管理者アカウントには多要素認証を用い、OSのマルウェア対策を継続運用します。ソースコードと依存関係を定期的に確認し、重大な問題が確認された場合は公開停止または修正を行います。

不正利用対策

Stripeが提供するカードテスティング対策、試行回数制御、リスク判定および必要に応じた3Dセキュアを利用します。不審な支払いは制作開始前に確認します。
